# Requirements and decisions

## Original brief (owner, 2026-11-13)
- An ONI base for exactly **8 duplicants + 6 bionics ("boops")**, all DLC enabled.
- Use blueprintnotincluded.org (BNI) to browse others' designs and produce ours. Search the web for references.
- Follow the ideas of these references:
  - 拿个破笔水: 【缺氧】8复制人+6仿生人混合基地二度重制版, https://www.bilibili.com/video/BV1Zi2EBYE25
  - 大叔追云彩's 8+6 base: https://www.bilibili.com/video/BV1PAm2B9Ed4/ and the Yuque doc https://www.yuque.com/u25332524/ftq4u7/ws1fao3eevlzfmmv
- **Compact and elegant**, fitting the usual **4-tile-tall storey grid**.
- **Reuse resources as much as possible**, e.g. one shared banquet hall with only one banquet (communal) table, made to work by scheduling.
- **End-game layout.**
- Duplicants **leave the base wearing atmo suits**.
- **Easy access up (to space) and down (to the bottom of the map)**, leaving room for **transit tubes going left and right**.
